📋 State Descriptions

  • STARTUP: Initial state when pairing is first activated
  • MEASURING: Reading soil moisture from SDI-12 sensor
  • DELAY: Processing sensor data and deciding next action
  • VALVE_OPEN: Actively irrigating (valve is open)
  • VALVE_CLOSE: Stopping irrigation (valve is closed)
  • IDLE: Waiting for next measurement cycle
  • DISABLED: Pairing is manually disabled/stopped

⏱️ Timing Configuration

  • measurementTime: Time to complete sensor reading (default: varies by sensor)
  • delayTime: Processing time between measurement and action (default: 1000ms)
  • valveOpenTime: Duration to keep irrigation valve open (configurable per pairing)
  • intervalTime: Time between measurement cycles (configurable per pairing)
