Technology

Measure. Decide. Irrigate. Verify.

A closed-loop plant-water system: sensors in the substrate, valves on each treatment, and live software that shows the experiment while it is happening.

01 sensing

Root-zone data

VWC, temperature, and EC readings from the substrate instead of guesswork from timers.

02 control

Pot-level irrigation

Automated watering by threshold so drought and control treatments stay intentional.

03 dashboard

Live experiment view

Researchers can see traces, export CSV, and catch sensor issues before data quality slips.

04 scale

Bench to range

Start with one experiment and expand to larger greenhouse layouts without redesigning the system.
