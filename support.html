FAQ

Common
questions

Don't see your question? Email us and we'll answer within 24 hours.

What substrates is exactH2O calibrated for?+
exactH2O sensors work in peat, perlite, rockwool, coco coir, field soil, and custom substrate mixes. Each substrate has distinct dielectric properties, so we provide substrate-specific calibration coefficients that you enter during setup. Custom calibration for novel substrates is available on request.
How many sensors and zones can one system support?+
The base system supports up to 16 sensor nodes. The mesh network architecture allows expansion to 400+ sensors by adding gateway nodes — no new wiring infrastructure is needed. Zones can be any logical grouping of sensors with shared irrigation targets.
Can I export data for use in R or Python?+
Yes. All sensor data is exportable as CSV or JSON directly from the web dashboard. A REST API is also available for live data integration into custom pipelines, enabling real-time connection to R, Python, JMP, or any data analysis environment.
What happens if a sensor fails during an experiment?+
The system monitors sensor health continuously and triggers configurable email or SMS alerts when a reading falls outside expected bounds or a sensor stops reporting. Failed sensors can be hot-swapped without interrupting other zones.
Is exactH2O compatible with existing fertigation controllers?+
Yes. exactH2O outputs standard control signals (relay-switched or 0–10V) compatible with most commercial fertigation controllers and solenoid valves. We can advise on integration with your existing equipment during the quote process.
How long does installation typically take?+
A standard 16-sensor greenhouse deployment typically takes 4–8 hours including sensor placement, network configuration, and dashboard setup. Larger deployments are usually completed over 1–2 days. We provide installation guides and offer on-site support for complex setups.
