# ExactH2O software showcase

24-second, silent product edit captured from the October 13 software release. The screenshots are unmodified browser captures; the edit adds a restrained camera move, short dissolves, titles and a brand close. Drought values are Binod's recorded values; the recovery and irrigation scenes are derived scenarios. The export scene contains all 122,990 readings available at the captured replay point.

The homepage poster, portal preview, MP4, VP9 WebM, captions and transcript ship together. Rebuild using `python3 scripts/render-showcase.py` with FFmpeg on PATH (or FFMPEG set). The current rendering uses macOS Arial fonts; equivalent fonts must be supplied if rendering on another OS. Temporary clips go outside the repository. Capture fresh product scenes before changing the edit; do not construct fake interface screenshots.
